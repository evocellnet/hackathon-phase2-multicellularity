ITEM 2. Bias of the inclusion rule ...................................................... PASS (no bias found)
  (a) Symmetric rule (>=3 origins' multicellular clades OR >=3 origins' sister clades OR >=50% of species): adds only BIR
      (PF00653; present in 3 sister clades, 2 multicellular clades) -> 13 families: b = +0.152, CI 0.032-0.272, p = 0.0068.
  (b) All 22 families (all present in the 148 species): b = +0.138, CI 0.026-0.249, p = 0.0078 (lambda at bound 1).
      The 10 excluded lineage-restricted families are mostly animal-specific (Bcl-2, BH4, CARD, Death, DED, gasdermin, HeLo,
      MazF ...); their individual PGLS coefficients are all positive, so the rule removed families that point the same way,
      it did not cherry-pick. The single strongest family is NB-ARC (per-family b = +0.60, p = 0.0002); caspase also p = 0.02.
  (c) Pipeline null: 200 random 22-family sets of non-cell-death Pfam families, each member matched to one cell-death family on
      prevalence in the 148 species (+/-0.025, widened if < 20 candidates), seed 11, run through the same rule + PGLS:
      rule kept median 13 families (11-16); p < 0.05 in 5/200 = 2.5% (not above 5%; binomial p = 0.97); mean b = -0.007,
      b > 0 in 43%. Without the rule (all members): p < 0.05 in 4.0%, mean b = +0.021. No random set reached b >= 0.167
      (empirical p < 1/200 for both). The selection + test pipeline is not biased toward multicellular species.

ITEM 3. Proteome size / annotation ....................................................... PASS, with a caveat
  Covariates in the primary P3 model: log proteome size b = +0.545 (two-sided p = 1e-13); disorder b = -0.788 (p = 0.026).
  Multicellular coefficient: no covariates +0.253 (p = 0.0006); size only +0.178 (p = 0.0032); full model +0.167 (p = 0.0047).
  Excluding the 10 largest proteomes (Paratet, Ephymue, Sycocil, Ceraric, Charbra, Selamoe, Paulmic, Capitel, Stencoe,
  Sphaarc; 6 of 10 multicellular): b = +0.121, p = 0.025 (standardisation kept) / b = +0.124, p = 0.027 (re-standardised);
  95% CI lower bound ~0.00. Sign holds and p < 0.05, but the effect shrinks by ~28% and would not pass Holm's 0.0167.
  Caveat (diagnostic, not pre-registered): proteome size is the dominant predictor. If counts are instead expressed as a
  proportion of proteome size (log(count/size), i.e. size slope forced to 1), b = +0.083, p = 0.14. The pre-registered model
  estimates the size slope (0.55) and that is the correct confirmatory test, but the result means "more cell-death proteins
  than expected for a proteome of that size under a sub-proportional scaling", not "a larger share of the proteome".

PLAIN LANGUAGE
  The claimed P3 and P2 numbers are exactly reproducible from the raw annotation files with independently written code.
  The family-selection rule does not create the P3 signal: adding the families it excluded, using a symmetric rule, or running
  the same pipeline on prevalence-matched random families gives either the same positive result (cell death) or nothing
  (random sets, false-positive rate 2.5%). The P3 effect is partly entangled with proteome size: it weakens (p = 0.025) when
  the 10 largest proteomes are dropped and disappears (p = 0.14) if abundance is measured as a fraction of the proteome.
  It is also heavily carried by NB-ARC (plant/fungal immune-receptor family); the producer already reports that dropping
  Streptophyta raises p to 0.078.
