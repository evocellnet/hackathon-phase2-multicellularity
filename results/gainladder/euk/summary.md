# Gain-evidence ladder: euk run

Generated by `scripts/gain_ladder.py` (mcell 0.1.0); definitions in `mcell/gainladder.py` and DESIGN §3.2. Descriptive only (no hypothesis tests).

* HOGs: `runs/euk_fast/hogs.orthoxml`; tree `runs/euk_fast/stages/input/guide_tree.nwk`.
* Scope: 107 selected branches (`runs/gainladder/euk/branches.tsv`: transition stems, path edges, grey/reversal stems, control pool U, and the edges above them; tip stems included).
* DIAMOND: `nice -n 5 diamond blastp -q runs/gainladder/euk/queries_pass1.faa -d runs/gainladder/db/all_euk_prok.dmnd -o runs/gainladder/euk/hits_pass1.tsv.gz.part --very-sensitive -k 0 -e 1e-05 --query-cover 30 --threads 20 -f 6 qseqid sseqid pident length evalue bitscore qcovhsp --max-hsps 1 -b 4 -c 1 --compress 1`; 163872 queries, wall 2364.8 s at 20 threads. Target DB: all eukaryote + prokaryote proteomes (identical for both runs). Two-pass: 122945 rank-0 representatives, then 40927 further representatives of gains still without an outside hit.
* Deviation from DESIGN §3.2: `--very-sensitive` instead of `--ultra-sensitive` (timing pilot: ~3.5x cheaper; on the simulations it calls 1-3% more gains novel; see `recheck_ultra.json` for the real-data check).

* **Split repair failed the DESIGN acceptance test on the simulations** (gain ratio stays 2.1-2.5x; `results/gainladder/validation_sim/summary.md`): level 2 is a diagnostic only; report levels 1 and 3. On the simulations seq-novel recall of true gains is 0.91-0.97 but precision only 0.42-0.56 (deep splits beyond detectable homology), so seq-novel counts are upper bounds.
