# Structure data (DESIGN.md §5, exploratory)

## Source
- AlphaFold Protein Structure Database (AFDB), EBI. Per-protein model files fetched from
  `https://alphafold.ebi.ac.uk/files/AF-<UniProtACC>-F1-model_v6.pdb` (stored gzipped as served);
  metadata/fallback via `https://alphafold.ebi.ac.uk/api/prediction/<ACC>` (gives `pdbUrl`, `latestVersion`, `globalMetricValue`).
- **AFDB version: v6** (current on 2026-10-28; `allVersions` for the probe entry = 3,4,5,6; v4 file URLs now return 404).
- Licence: **CC BY 4.0** (AlphaFold DB: Jumper et al. 2021 Nature; Varadi et al. 2022/2024 NAR).
- Access notes: a non-default `User-Agent` header is mandatory (curl default -> HTTP 403); the GCS bucket returns 401 (not used).
  **Rate limit:** EBI answers HTTP 429 above ~3.3 requests/s sustained per IP (measured: 3.0/s for 400 s OK; 4/s -> 429 after ~330 requests;
  block lasts 1-2 min, no Retry-After). The fetcher (`scripts/structure/afdb_fetch.py`) uses a global limiter at 3.0 req/s
  (<=8 connections, <=16 allowed), 90 s global pause + 15% rate cut on 429, retries with exponential backoff, atomic `.part` -> rename,
  gzip integrity check, resume by skipping existing files and previously logged 404s. Expect **~12-13 h** for ~124k proteins.
  The 16-parallel/1-1.5 h estimate in reviews/round2 is not achievable under the current limit.
- Foldseek 10.941cd33 (`conda_envs/ancestra/bin/foldseek`; no separate env needed).

## Reference species (data/structure_species.tsv)
11 UniProt-sourced unicellular P-side species for the 7 primary transitions, 123,882 proteins (cap ~120k):
Monobre, Salpros (T_metazoa); Gonapro (T_fungi_hyphae); Planfun (T_dictyostelia); Ostrtau, Micrcom (T_streptophyta);
Porppur, Rhodmar (T_rhodophyta); Nannsal, Phaetri (T_px_filaments); Chlarei (T_volvocine_tgv).
Selection = UniProt-sourced (species_final.tsv `source_db`), unicellular, smallest topological distance to the transition's M species
in `data/guide_tree_euk.nwk`; <=2 per transition; congeners/near-duplicates dropped for the cap. Caveats: for T_dictyostelia and
T_streptophyta all true sister species in the data are EukProt-only, so the reference is an outgroup (Variosea; Chlorophyta);
T_dictyostelia has a single reference (Acancas, +14.9k, optional 2nd); T_fungi_hyphae one (Pirofin, 10.8k, tied; optional).

## novel_gain_structures.py: method
Input TSV `accession, transition_id[, set, sequence]`; fetches AFDB model (cached under runs/structure/query_models), keeps mean pLDDT >= 70,
`foldseek easy-search --exhaustive-search 1 -e 1e-3 --max-seqs 1000` (3Di+AA alignment, alignment-type 2, prefilter bypassed) against the
transition's P-side DB. **Structurally old** = >=1 hit with E <= 1e-3 and TM >= 0.5; default TM = `qtmscore` (query-length normalised; option
`--tm-metric q|t|max|min|aln`); alntmscore/qtm/ttm of the best hit always reported. Note alignment-type 1 (TM-align) was rejected as the
search mode: it returns uninformative E-values (~0.5) and is ~6x slower; the TM columns from type 2 are computed from the 3Di+AA alignment.
Output `<prefix>.queries.tsv` and `<prefix>.summary.tsv` (fraction old among searched, and among all queries, per transition x set;
use set=gain / control for control-branch gains). Optional `sequence` column is checked against the model SEQRES. Models absent from AFDB
(`no_model`) and pLDDT < 70 (`low_plddt`) are counted separately, so the denominator is explicit.

### Tests (2026-10-28, partial DB; see below)
Positive: 187 Ostrtau models vs a 968-model Micrcom DB (~10% of the proteome): 30/122 pLDDT-pass queries hit (expected given coverage);
vs. a T_streptophyta DB containing the query proteins: 16/16. Negative: 60 models with residue order shuffled -> 0/42 hits (E <= 1e-3, TM >= 0.5).
Throughput: 164 queries x 968 targets exhaustive = 4 s on 2 threads.

## Fallback reference: AFDB Swiss-Prot (`--ref swissprot`)
- `foldseek databases Alphafold/Swiss-Prot` (1.5 GB download, ~2 min; 590,183 models, AFDB v6 file names) -> `runs/structure/afdb_sp/sp` (+ `sp_mapping` key -> NCBI taxid, `sp.lookup`).
  (The foldseek call's final `mvdb` failed because the output dir did not exist; files were moved by hand. Create the dir first next time.)
- A query is 'structurally old' if it has a hit with E <= 1e-3 and TM >= 0.5 (same thresholds) to a Swiss-Prot model whose NCBI taxon is
  OUTSIDE the transition's multicellular clade M. M is defined per transition in `data/structure_ref_exclusion.tsv`
  (excluded taxa + exceptions; NCBI taxdump `data/raw/taxdump`). Hits inside M are counted (`n_hits_in_M_excluded`) and ignored;
  `best_taxid`/`best_taxon` reported. Notable: NCBI places Cyanidiales inside Bangiophyceae, hence an exception for T_rhodophyta;
  Amastigomycota is not an NCBI taxon -> Dikarya+Mucoromycota+Zoopagomycota.
- Cost: exhaustive search vs 590k targets ~8 s wall per query (4 threads); `--prefilter` is much faster but less sensitive.
- Query fetching: 1 request per unique accession (no API call unless the file 404s), cached in runs/structure/query_models, and the 3 req/s
  limiter is now shared across processes via a flock-ed state file (runs/structure/.afdb_rate_state), so query runs and the reference download together stay under the EBI limit.
- Test (T_metazoa, human queries): actin P60709 -> S. pombe actin (TM 1.00), calmodulin -> Plasmodium CaM (0.98), globin -> Physcomitrium (0.84), Q8N3Y1 -> S. pombe (0.55): all old;
  p53 (metazoan-specific-like) -> weak yeast hit TM 0.27: not old; 9/9 pLDDT-pass shuffled models: 0 hits.
