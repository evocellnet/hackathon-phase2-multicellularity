## Processing (summary; details in `scripts/data/` and `data/guide_tree_edits.md`)

- One protein per gene: UniProt canonical FASTA (+ gene2acc group collapse); NCBI longest protein per GFF gene; EukProt/LukProt genome sets longest protein per parsed gene ID (isoforms present in e.g. Sycon, Chromera, Cyanophora); transcriptomes longest ORF per Trinity/SOAP gene where headers allow, then `cd-hit -c 0.95 -G 0 -aS 0.9 -n 5`.
- Cleaning: terminal `*` trimmed, internal stops / non-standard letters -> X, length >= 50 aa, exact duplicate sequences removed within species. IDs `<code>_<original id>` (characters outside [A-Za-z0-9_.-] -> `_`); mapping tables in `data/proteomes/idmaps/<code>.tsv.gz`.
- QC: BUSCO 6.1.0 protein mode with the odb10 lineages above; `low_quality = 1` if C < 50 %; `flag_DF15 = 1` for transcriptome-derived sets with D or F > 15 %.

## Eukaryote protein cap (PI rule, 2026-10-28)

Hard cap: **3.0 M eukaryote proteins** (Ancestra peak memory within the 150 GB allocation). Written rule, applied by `apply_cap()` in `scripts/data/select_final.py` after preprocessing: drop taxa in order (1) tier = optional AND role = background, largest number of final proteins first; (2) then other optional taxa, largest first, only if every transition side they are on keeps >= 2 species; never drop the only representative of a transition side. Stop as soon as the total <= 3.0 M. Result: 10 taxa dropped, total 2,969,261 proteins in 187 eukaryotes (`data/species_cap_drops.tsv`).
